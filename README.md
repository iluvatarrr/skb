Использовал Spring Security.
Реализовал приложение с разделением прав доступа с использованием аннотации javax.annotation.security.RolesAllowed
АПИ:
- public/api - доступ разрешен для всех
- admin/api - доступ разрешен для пользователей с ролью admin
- support/api - доступ разрешен для пользователей  с ролью support
Приватные АПИ возвращают имя и роль пользователя
Хранение пользователей в памяти приложения (InMemoryUserDetailsManager)
Для хеширования паролей добавлен бин BCryptPasswordEncoder
Используется Basic аутентификация
