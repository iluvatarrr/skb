### @SpringBootApplicatoin - Мы используем эту аннотацию для обозначения основного класса приложения Spring Boot. Она автоматически включает конфигурацию, сканирование компонентов и автоконфигурацию.
### Аннотация @SpringBootApplicatoin содержит в себе:
-**@SpringBootConfiguration** – помечает класс как конфигурационный, регистрация дополнительных бинов в контексте.<br>
-**@ComponentScan** – включает сканирование компонентов, то есть классы-контроллеры и другие компоненты, которые вы создаете, будут автоматически зарегистрированы как бины в application context.<br>
-**@EnableAutoConfiguration** – под капотом запускает весь механизм автоматической конфигурации Spring Boot.<br>
### Параметры:
-**exclude:** позволяет исключить определенные классы автоматической конфигурации<br>
-**excludeName:** позволяет указать имена классов конфигурации для исключения<br>
-**proxyBeanMethods:** позволяет управлять поведением проксирования бинов в рамках контекста Spring<br>
-**scanBasePackages:** используется для задания базовых пакетов, которые Spring должен просканировать на наличие аннотированных компонентов<br>
-**scanBasePackageClasses:** предоставляет гибкий и безопасный способ указания базовых пакетов, которые следует просканировать на наличие компонентов<br>
-**nameGenerator:** позволяет настраивать стратегию именования для компонентов, которые будут зарегистрированы в контексте Spring<br>
