Создал мультимодульный проект, содержащий:
    -consumer
    -producer
Реализовал задание:
1) Реализовать два сервиса, способные обмениваться сообщениями с использованием одного из сервисов (на выбор ActiveMQ, RabbitMQ, Kafka)
2) Тело сообщения должно быть в формате JSON
3) Пришедшее сообщение выводить в лог
Доп.Задание:
id – Id этого листенера
topics / topicPattern - Топики для прослушивания
groupId - Группа потребителей
containerFactory - Название бина для лиснера
autoStartup - Автоматически стартовать листенер
concurrency - Число потоков обрабаботки сообщения
splitIterables – Разделение сообщений
beanRef - Ссылка на бин листенера
idIsGroup - Id используется как groupId
errorHandler - Обработчик ошибок
containerPostProcessor - Дополнительные настройки перед стартом приложения
info - Описание листенера
containerGroup - Группировка контейнеров слушателей
clientIdPrefix – Префикс к id клиента в Kafka
topicPartitions – Партиции для прослушивания
filter - Фильтрация
contentTypeConverter - Указание на бин своего десериализатора
properties - Доп.свойства
batch - Получение пачками сообщений
